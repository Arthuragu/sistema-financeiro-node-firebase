# Projeto Financeiro - AT2N2

## Como rodar o projeto

1. Acesse o **Firebase Console**, vá em **Configurações do Projeto > Contas de Serviço** e clique em **Gerar nova chave privada**.
2. Renomeie o arquivo JSON baixado para `serviceAccountKey.json` e coloque-o na raiz desta pasta (`projeto-financeiro/`).
3. No terminal, dentro da pasta `projeto-financeiro`, instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor Node.js:
   ```bash
   npm start
   ```
5. Abra o navegador em `http://localhost:3000`.
